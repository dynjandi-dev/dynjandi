Uploadcare URL checker

Paste an Uploadcare URL to see the Dynjandi URL it becomes and which of its operations Dynjandi does not support. Nothing is sent anywhere: the URL is read in this page and never requested.

For example https://ucarecdn.com/<uuid>/-/resize/800x600/-/format/webp/

The rewrite assumes the file was imported to Dynjandi and kept its Uploadcare UUID as its file id, so only the host changes. This page states what the URL grammar accepts, not whether the file exists or the CDN will serve it.
